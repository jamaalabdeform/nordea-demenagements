# Nordéa Déménagements — démo STIPway

Site vitrine, simulateur de volume et de devis, back-office des demandes et paiement d'acompte pour un déménageur.
**La marque et toutes les coordonnées sont fictives** (démonstration commerciale).

```bash
npm install
npm run dev
```

- Site : `/` · Simulateur : `/devis` · Page locale : `/demenagement-lille`
- Espace entreprise : `/admin-demo` (code `nordea-demo`)
